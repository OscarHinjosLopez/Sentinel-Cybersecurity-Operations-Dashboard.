# Changelog

## 1.0.0

First portfolio release, prepared for publication.

- Foundation: strict standalone Angular 22, zoneless bootstrap and feature-first lazy routing.
- Design System: Material/CDK, local icons, semantic SCSS tokens, responsive shell and light/dark themes.
- Auth/RBAC: mock sessions, route guards and permission-aware actions for Admin, Analyst and Viewer.
- Dashboard: SOC KPIs, range selection, activity feed and deferred modular ECharts.
- Threat Management: URL-driven search, filters, sorting, pagination, investigation and local resolution.
- Devices: inventory, posture details, mock scans and local isolation/restoration.
- Realtime: typed simulated transport, validation, deduplication, ordering and reconnection.
- Advanced UX: notifications, command palette, keyboard shortcuts and browser preferences.
- Testing: Vitest unit/integration, coverage gates, Playwright, axe and GitHub Actions.
- Performance/A11y: reduced initial bundle, focus management, reduced motion and 200/400% browser zoom checks.
- Release: Docker/nginx, Vercel configuration, production smoke, screenshots, architecture and portfolio case study. No new product functionality.
